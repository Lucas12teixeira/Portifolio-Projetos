## 🎯 Visão Geral

**American Teens** é uma plataforma digital abrangente projetada para comunidades de ministério jovem. Construída como uma Progressive Web App (PWA), combina recursos de redes sociais com ferramentas de crescimento espiritual, criando um ambiente envolvente e seguro para jovens membros se conectarem, aprenderem e crescerem juntos.

### 🎯 Problema Identificado

Ministérios jovens modernos enfrentam desafios em:
- Manter engajamento fora de reuniões físicas
- Coordenar eventos e atividades eficientemente
- Fornecer recursos espirituais acessíveis
- Promover conexões significativas entre membros
- Gerenciar informações de membros com segurança

### 💡 Solução Implementada

American Teens resolve esses desafios fornecendo:
- **Plataforma Unificada**: Solução completa para comunicação, eventos e recursos
- **Design Mobile-First**: Acessível em qualquer lugar, a qualquer hora, em qualquer dispositivo
- **Capacidades Offline**: Funciona sem conexão à internet através de tecnologia PWA
- **Seguro e Privado**: Controle de acesso baseado em funções e proteção de dados
- **Arquitetura Escalável**: Suporta crescimento de pequenos grupos a grandes comunidades

### 🌟 Por Que Este Projeto Se Destaca

- ✅ **Zero Dependências de Frameworks**: Construído com JavaScript vanilla para máxima performance
- ✅ **Pronto para Produção**: Em operação e servindo usuários reais
- ✅ **Conjunto Completo de Features**: Não é uma demo - totalmente funcional com 12+ módulos integrados
- ✅ **Impacto Real**: Ativamente usado por comunidades de ministério jovem
- ✅ **Arquitetura Profissional**: Código limpo, APIs documentadas, melhores práticas de segurança

## ✨ Funcionalidades Principais

### 🔐 Autenticação e Autorização
- **Autenticação segura baseada em JWT** com suporte a refresh token
- **Controle de acesso baseado em funções** (Admin, Coordenador, Membro)
- **Sistema de recuperação de senha** com verificação por email
- **Gerenciamento de sessões** com atualização automática de tokens

### 💬 Sistema de Chat em Tempo Real
- **Mensagens individuais** com indicadores de digitação
- **Rastreamento de status online/offline**
- **Confirmações de leitura de mensagens**
- **Capacidade de bloqueio de usuários**
- **Busca e filtragem de conversas**
- **Suporte a compartilhamento de arquivos** (imagens, documentos)
- **Polling em tempo real** para entrega instantânea de mensagens

### 📅 Gerenciamento de Eventos

## 🏗 Arquitetura

### **Single Page Application (SPA)**
```
┌─────────────────────────────────────────────────────────┐
│                    Cliente (Navegador)                   │
├─────────────────────────────────────────────────────────┤
│  App.js (Roteador)                                      │
│    ├─ Módulo de Autenticação                            │
│    ├─ Módulo de Chat                                    │
│    ├─ Módulo de Eventos                                 │
│    ├─ Módulo de Bíblia                                  │
│    ├─ Módulo de Quiz                                    │
│    ├─ Módulo de Mural                                   │
│    └─ Módulo de Perfil                                  │
├─────────────────────────────────────────────────────────┤
│  Service Worker (Cache Offline)                         │
└─────────────────────────────────────────────────────────┘
                          ↕ HTTPS
┌─────────────────────────────────────────────────────────┐
│                    API REST (PHP)                        │
├─────────────────────────────────────────────────────────┤
│  api/index.php (Roteador)                               │
│    ├─ auth/*                                            │
│    ├─ chat.php                                          │
│    ├─ events.php                                        │
│    ├─ members.php                                       │
│    ├─ quiz-v2.php                                       │
│    └─ verse-of-day-routes.php                          │
└─────────────────────────────────────────────────────────┘
                          ↕
┌─────────────────────────────────────────────────────────┐
│                   Banco de Dados MySQL                   │
├─────────────────────────────────────────────────────────┤
│  ├─ members                                             │
│  ├─ chat_conversations                                  │
│  ├─ chat_messages                                       │
│  ├─ events                                              │
│  ├─ quiz_questions                                      │
│  ├─ revelacao (sistema de testemunhos)                  │
│  └─ verses_of_the_day                                   │
└─────────────────────────────────────────────────────────┘
```

### **Padrões de Design Chave**
- **Padrão de Módulo** - Funcionalidade encapsulada em módulos separados
- **Padrão Observer** - Comunicação orientada a eventos entre componentes
- **Padrão Repository** - Camada de abstração do banco de dados
- **Padrão Factory** - Criação dinâmica de componentes
- **Padrão Singleton** - Serviços de instância única (Auth, API Client)

## 🔒 Segurança

### **Medidas de Segurança Implementadas**

✅ **Autenticação**
- Autenticação baseada em JWT com assinatura segura
- Rotação de refresh tokens
- Hashing de senhas com bcrypt (fator de custo 12)
- Timeout de sessão e logout automático

✅ **Validação de Entrada**
- Validação server-side para todas as entradas
- Prevenção de injeção SQL (prepared statements)
- Proteção XSS (codificação de saída)
- Validação de token CSRF

✅ **Segurança da API**
- Configuração CORS
- Rate limiting
- Limites de tamanho de requisição
- Verificações de autorização em todos os endpoints

✅ **Proteção de Dados**
- Imposição de HTTPS
- Flags de cookies seguros (HttpOnly, Secure, SameSite)
- Criptografia de credenciais do banco de dados
- Opções de anonimização de dados de usuários
